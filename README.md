## Overview
Web Crawler is a Python-based project developed to automate the process of visiting and analyzing web pages and extracting useful information from them. Instead of manually opening multiple web pages and collecting data, the crawler automatically sends requests to a given URL, retrieves the webpage content, and parses its HTML structure. It uses libraries such as Requests to communicate with websites and BeautifulSoup to analyze and extract data from HTML documents.


## Tech Stack
- Python
- Requests
- BeautifulSoup
- HTML
- Web Scraping


## System Requirements
- Windows, macOS, or Linux

- HTTP Requests
- Web Scraping
- HTML Parsing
- DOM Structure
- URL Handling
- Data Extraction
- Link Extraction
- Loops and Functions
- Exception Handling


## Main Features
- Accepts a starting URL
- Fetches webpage content
- Extracts information from HTML
- Extracts links from webpages
- Follows discovered links
- Collects and displays scraped data
- Handles invalid URLs and request errors

## How to Run
1. Clone or download the project.
2. Open the project folder in VS Code.
3. Install the required libraries:
```pip install requests beautifulsoup4```

4. Run the Python file:
```python main.py```

5. Enter the URL when prompted.
